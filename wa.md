# Team Working Agreement

## Communication

**Primary Channels:**
- Discord & MS Teams for daily collaboration and quick updates
- Email for formal communications and external contacts

**Response Time:**
- Team messages: Within 24 hours on weekdays
- Urgent issues: Tag with @urgent for same-day response

## Development Workflow

**Platform & Tools:**
- WordPress (CMS)
- BlueHost (Hosting & Security)
- Visual Studio Code (Development)
- Jira (Project Management)
- GitHub (Version Control)

**Code Management:**
- All code changes must be pushed to GitHub
- Create feature branches for new work
- Require code review before merging to main
- Write clear commit messages

**Task Management:**
- Track all tasks in Jira
- Update task status daily
- Participate in sprint planning and retrospectives
- Flag blockers immediately

## Meeting Guidelines

- Sprint planning: Start of each sprint
- Daily standups: As needed (async updates in Discord/Teams)
- Sprint reviews: End of each sprint
- Be on time and come prepared
- Share agenda in advance when possible

## Quality Standards

- Test changes locally before pushing
- Follow WordPress coding standards
- Maintain documentation for major features
- Security first: No sensitive data in code

## Team Commitments

✓ Respect each other's time and expertise  
✓ Communicate openly about challenges  
✓ Support team members when needed  
✓ Take ownership of assigned tasks  
✓ Maintain a positive, collaborative environment
